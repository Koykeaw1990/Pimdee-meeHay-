# ระบบติดตามงานขาย · บริษัท พิมพ์ดีมีเฮ จำกัด

เว็บสำหรับติดตามงานขายของโรงพิมพ์ทีละขั้น ตั้งแต่ใบเสนอราคาจนรับเงินค้ำประกันคืน

## ขั้นตอนการขาย 8 ขั้น
1. สร้างใบเสนอราคา
2. สั่งงาน
3. ส่งผลิต (กำหนดวันส่งงาน)
4. เช็คสถานะการส่งงาน
5. เช็คสถานะการชำระเงิน (เลขที่ใบส่งของ)
6. เช็คสถานะการส่งใบเสร็จรับเงิน (เลขพัสดุ)
7. เช็คสถานะการส่งเอกสารถอนค้ำประกัน (เลขพัสดุ)
8. เช็คสถานะการรับเงินค้ำประกันคืน (เลขพัสดุ)

## ทำอะไรได้บ้าง
- บอร์ดแสดงงานแยกตาม 8 ขั้น
- เพิ่มงานใหม่ พร้อมแนบไฟล์ใบเสนอราคา และดึงชื่อลูกค้าจากไฟล์ Excel ให้อัตโนมัติ
- กดเปลี่ยนสถานะแต่ละขั้น ยังไม่เสร็จ ↔ เสร็จแล้ว
- ใส่เลขพัสดุ แล้วกดตรวจสถานะกับไปรษณีย์ไทย, Kerry, Flash, J&T
- สรุปงานที่เสร็จครบทุกขั้นในแต่ละวัน

## วิธีเปิดใช้งานบนเครื่อง
ต้องมีโปรแกรม Node.js ในเครื่องก่อน จากนั้นเปิดหน้าต่างคำสั่งในโฟลเดอร์นี้ แล้วพิมพ์

```
npm install
npm run dev
```

แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3001

ข้อมูลงานและไฟล์ที่แนบจะเก็บในโฟลเดอร์ `data` บนเครื่องเท่านั้น ไม่ได้อัปโหลดขึ้น GitHub
